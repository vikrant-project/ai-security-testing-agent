# Security reporting

This project contains testing instructions and helper scripts. Security issues in the helpers may include incorrect APK admission, scope-check errors, credential disclosure, or unsafe evidence-path handling.

Do not publish exploit details that expose a private system, real credentials, personal app data, or proprietary APKs in a public issue. Use this repository's private vulnerability reporting option when it is enabled. If unavailable, open a minimal issue requesting a private contact channel without sensitive details.

Include the helper/version, platform, minimal synthetic reproduction, expected versus actual behavior, and demonstrated impact. Use temporary test artifacts and redacted configuration. Do not test another person's systems to produce a report.

The project does not promise a response time or a bug bounty. Vulnerabilities discovered in assessed applications should go to the relevant application owner, rather than this project's issue tracker.
