# Repository discovery and sharing

The repository is titled and described around its actual capability: AI agent skills for Android debug APK security testing, ADB live testing, Flutter/Kotlin source review, and staging web/API assessments.

## Included discoverability features

- A descriptive repository name and About description.
- Twenty relevant GitHub topics that match the implementation and documentation.
- An English README with specific use cases, setup examples, prerequisites, limitations, and links.
- A checked-in banner with descriptive alternative text, a coverage chart, and workflow diagrams.
- A public license, contribution guide, security-reporting guidance, and offline validation workflow.
- A concise set of share hashtags rather than repeated hidden keywords.

GitHub topics help repositories appear in topic browsing and topic search. See [GitHub's topic documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics). The image checked into the README is separate from GitHub's repository social preview setting, which is configured through the repository settings UI.

## Ways to build useful visibility

Publish a real, redacted walkthrough on an app you own; show its configured scope, actual gate output, and one reproducible finding or validated negative test. Link this repository from the app's testing documentation. Accept reproducible feedback and keep examples current. Share a short description with relevant developer communities under their rules, without unsolicited messages or artificial engagement.

Suggested share text:

> AI Security Testing Agent: an open-source SKILL.md workflow for verified debug APKs, ADB live app testing, Flutter/Kotlin review, and local or staging web/API assessments. Includes scope checks, reproducible evidence, resumable state, and offline validation helpers. https://github.com/vikrant-project/ai-security-testing-agent

Suggested hashtags: `#AISecurity #AgentSkills #AndroidSecurity #Flutter #Kotlin #APISecurity #SecurityTesting`

Search engines and AI retrieval systems control indexing and rankings. Repository topics, hashtags, and documentation cannot guarantee instant Google indexing or the first result. A GitHub repository does not provide owner control over arbitrary HTML metadata, search-engine verification, or a custom sitemap. If a separate owned documentation site is added later, configure its metadata and indexing tools through that site's host; this publication does not deploy a separate website.
